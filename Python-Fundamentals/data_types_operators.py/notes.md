# Day 1 Notes: Data Types & Operators

## Key Learnings
- Python has built-in data types: int, float, str, list, tuple, set, dict, bool.
- Operators allow manipulation: arithmetic, comparison, logical, assignment, membership, identity.

## Challenges
- Remembering difference between `is` (identity) vs `==` (equality).
- Understanding mutable vs immutable types.

## Applications
- Data types form the foundation for ML datasets.
- Operators are used in preprocessing, filtering, and decision-making logic.
